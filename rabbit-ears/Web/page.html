Receiver — the aerial socket and the tuner (changes instantly)

Channels — what each transmitter puts out (changes instantly)

The set — PALindrome's own knobs (each change = a new decoder)

Hover a label for what it does. Orange = moved from its default. With "seamless" off you see the honest behaviour: every knob change re-locks the set, because the decoder's configuration is fixed when it starts.
