# Wing Walker integration surface

The two native part templates and rendering support target KSA 2026.11.10.5801. The earlier
implementation passed build, managed and native XML checks. The appearance fix passes the focused
and full solution builds, distribution check and 5801 native signature/CPU animation probe; the
updated production fixture passes, while in-game visual acceptance remains pending. The authoritative game sources are
`repos/ksa-game-assemblies/current/decomp/KSA` and `current/Content` in the enclosing workspace.

All durable state is native: part template determines posture, and KSA saves parts, `IVASeatData`,
roster, tank and life-support state. No save participant or sidecar is needed; rendering scope and
appearance overrides, weak animation markers and diagnostics are transient. Custom chair and strap art replace visual references and collider data while retaining both part
IDs, all five legacy subpart IDs/keys/order, CrewSeat/EvaDoor ownership and the save format.
Editor tags are static template metadata and add no saved scene state. See [saves](saves.md) and [native acceptance](../plans/WING_WALKER.md).
