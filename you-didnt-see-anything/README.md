# You Didn't See Anything legacy host

The supported distribution is the Unscience toolbox. This template-based standalone host exists for development and is not independently published; F11 opens its settings window. It does not install the Unscience native-save coordinator, so its options are session-only. Do not load it alongside Unscience, which already contains the same feature.

See [the library README](../you-didnt-see-anything.lib/README.md) for controls and integration details.
